CNC Machine Tool Terminology — English · 繁體中文 · 한국어

Machine-tool vocabulary does not translate cleanly. The same part is a 動力刀座 in a Taiwanese quotation, a live tool holder in an English specification and a 라이브 툴 홀더 in a Korean purchase order — and a mismatch between those three is how the wrong part gets shipped. These are the 196 terms we most often have to reconcile across a quotation, a drawing and a packing list.
